#### def __ init__(self, wavelet_type='ricker', wavelet_freq=30, dt=0.002)
*Класс задает параметры экземпляра по умолчанию:*
- **wavelet_type='ricker' : str**
	тип волны по умолчанию - рикер, других пока нет
- **wavelet_freq=30 : float**
	частота 30 (Гц)
- **dt=0.002 : float**
	интервал дискретизации в 0.002 (с)
- **lenght=0.128 : float**
	длительность импульса в секундах (должна быть достаточно большой, чтобы импульс затух до нуля)
значения **wavelet_time** и **wavelet** определяются вызовом _ create_ricker_wavelet()

#### def generate_trace(self, reflectivity_series, noise_level=0.0)
*Публичный метод, для создания синтетической сейсмической трассы:*
- **reflectivity_series : np.ndarray** 
	массив коэффициентов отражения (по времени). Длина массива определяет длительность трассы в отсчётах.
- **noise_level : float**
	уровень аддитивного белого шума (0 = нет шума, 0.1 = 10% от RMS сигнала)
свертывает коэфициенты отражения с импульсом
сокращает длину до reflectivity_series
добавляет шум
плюсует к трассе шум и возвращает результат (**trace**, синтетическая трасса той же длины, что reflectivity_series)
